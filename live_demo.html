Correlation Rule Example

Splunk query for detecting brute-force attacks:

index=windows sourcetype=WinEventLog:Security EventCode=4625
| stats count by src_ip, user
| where count > 10
| eval severity="HIGH"
| table _time, src_ip, user, count
